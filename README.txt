Análisis de reseñas de restaurantes de Sentimiento con BETO y LoRA

Este repositorio contiene una solución para la clasificación automática de sentimiento en reseñas gastronómicas, utilizando el modelo Transformer BETO y Fine-Tuning Eficiente con LoRA.

Requerimientos.
- Python 3.10+
- PyTorch con soporte para CUDA (Se recomienda GPU NVIDIA T4 x2 / P100)

Instalación

1. Clonar el repositorio:

git clone https://github.com/gersainsalvador-022/Proyecto-integrador-X/blob/main/proyecto-integrador-x-final.ipynb
